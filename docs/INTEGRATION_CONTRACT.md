# Integration contract

Backend is Python FastAPI at /api/v1; Pydantic models generate OpenAPI types.
One root-owned Store and scheduler; no other module writes SQL directly.

Voxel interface owned by voxel task: `voxlush.voxel.adapter.build(source: str, task: dict, destination: Path, config: dict | None = None) -> dict` writes authored_source.py, build.py, sample.json, voxels.npz, palette.json, components.json, geometry.json. Returns geometry report with passed, violations, canonical_voxel_hash, annotation_hash. `render(destination: Path) -> dict` writes previews/view_a.webp and view_b.webp plus contact.webp, returns image hashes. `primitive_contract() -> str` is identical for author and repair. `doctor() -> dict` probes local isolation without paid calls. Runtime files package inside voxel/resources. Category and task quality contract select gate. Pure core arrays functions in voxel/canonical.py.

Task dict: sample_id, campaign_id, seed, theme_seed_id, theme_family_id, scene_type, quality_contract, generation_mode (direct/two_stage), instruction, requested_tags, sampling_tags, quality_requirements. Geometry errors retained in full. Skeleton build uses task phase=skeleton; final uses phase=final.

Frontend: API reads GET health/live, health/ready, overview?campaign_id=ID, campaigns, samples?campaign_id=ID&limit=50&cursor=ID&status=STATUS, samples/{id}, coverage?campaign_id=ID, metrics?campaign_id=ID, config; SSE /events?campaign_id=ID&after=cursor. overview fields: campaign_id,state,reason_code,target,accepted_unique,provisional_pass,active_requests,effective_cap,configured_cap,requests_used,requests_limit,cost_known,cost_unknown,accepted_per_hour,window_seconds,queues [{stage,ready,running,oldest_wait_seconds}],event_cursor,server_time. samples response {items,next_cursor}; each item sample_id,campaign_id,stage,status,reason_code,theme_seed_id,scene_type,revision,updated_at,preview_artifact_id. Detail adds task, artifacts [{artifact_id,name}],events,attempts. Registered artifact GET /artifacts/{id}.

Control POST /commands {command_id,campaign_id,action,expected_config_revision:1,payload:{}} -> {command_id,status:queued/applied/rejected,reason}. GET /commands/{id}. Campaign POST {campaign_id,name,target,request_limit,api_cap,scene_weights:{architecture:.6,natural:.25,hybrid:.15}}. GET campaigns {items:[{campaign_id,name,state,target,accepted_unique,config_revision,requests_used,requests_limit}]}. Config is redacted. Config validate POST config returns {valid,errors}. Export POST {export_id,campaign_id,include_provisional:false} -> export job; GET /exports/{id}. Cookies from POST /session {token}; no credentials stored browser-side. Write requests require same Origin.

Coverage {items:[{family_id,name,scene_type,target,accepted,active,rejected,duplicate,debt,qualification,reason_code}],totals:{...}}. metrics {items:[{minute,accepted,requests,active_requests,effective_cap}]}. SSE event `snapshot` or `reset` payload full overview plus schema_version/event_id/server_time; no implicit mock fallback.
